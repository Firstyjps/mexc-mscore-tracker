# MEXC M-Score Tracker

Chrome extension ที่เก็บประวัติ M-Score ของ MEXC ทุกวัน และแสดงเป็น Dashboard ไม่ต้องมี server ไม่ต้องสมัครบัญชี และไม่ต้องลงโปรแกรมอื่น

โปรเจกต์ส่วนตัว ไม่ใช่ผลิตภัณฑ์ทางการของ MEXC โลโก้และชื่อ MEXC เป็นของเจ้าของเครื่องหมาย

## ติดตั้ง

1. กด **Code → Download ZIP** บนหน้านี้ แล้วแตกไฟล์ไว้ในที่ที่จะไม่ลบ เพราะ Chrome ใช้งานจากโฟลเดอร์นี้โดยตรง
2. เปิด `chrome://extensions` แล้วเปิด **Developer mode** มุมขวาบน
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์ `extension` ที่อยู่ข้างในโฟลเดอร์ที่แตกไฟล์
4. เข้าสู่ระบบ [MEXC](https://www.mexc.com/user/m-score) ในเบราว์เซอร์เดียวกัน
5. กดไอคอน M-Score Tracker แล้วกด **อัปเดตตอนนี้**

ใช้กับเบราว์เซอร์ตระกูล Chromium ได้ เช่น Chrome, Edge, Brave และ Dolphin

## ทำอะไรได้บ้าง

- เก็บคะแนนและ 5 ด้านวันละแถว เมื่อเปิดเบราว์เซอร์และทุก 3 ชั่วโมงระหว่างที่เบราว์เซอร์เปิดอยู่
- แสดงคะแนนบนไอคอน พร้อมกราฟ ตารางรายวัน และระยะห่างถึง tier ถัดไป
- แจ้งเตือนเมื่อคะแนนลดตั้งแต่ 10 แต้ม หรือเมื่อ MEXC ระงับคะแนน
- บอกเมื่อคะแนนลดทั้งที่ 5 ด้านไม่ลด ซึ่งเป็นกรณีที่ควรถาม MEXC Support
- แยกข้อมูลตามบัญชีให้อัตโนมัติ

## ใช้หลายบัญชี

เมื่อมีตั้งแต่ 2 บัญชี ด้านบนจะแสดงทุกบัญชีพร้อมคะแนน tier และวันที่อ่านล่าสุด กดเพื่อดูรายละเอียดแต่ละบัญชี

extension อ่านได้เฉพาะบัญชีที่ login อยู่ในเบราว์เซอร์นั้น จึงมี 2 วิธี:

- **สลับ login ในเบราว์เซอร์เดียว:** ระบบแยกข้อมูลให้เอง แต่จะได้คะแนนใหม่ของบัญชีนั้นเฉพาะตอน login อยู่
- **แยกเบราว์เซอร์หรือ profile ต่อบัญชี:** ติดตั้งทุกที่ แล้วกด **สำรองข้อมูลเป็นไฟล์** จากแต่ละที่ และ **นำเข้าไฟล์สำรอง** มาที่เดียว เลือกหลายไฟล์พร้อมกันได้ การรวมนี้เป็นการทำเอง ไม่ได้อัปเดตอัตโนมัติ

## ข้อจำกัด

- ถ้าไม่ได้เปิดเบราว์เซอร์ทั้งวัน วันนั้นจะไม่มีข้อมูล เพราะคะแนนย้อนหลังดึงจาก MEXC ไม่ได้
- ถ้า session ของ MEXC หมดอายุ Dashboard จะเตือนให้เข้าสู่ระบบใหม่
- ระบบใช้ API ภายในเว็บ MEXC ซึ่งอาจเปลี่ยนได้โดยไม่แจ้งล่วงหน้า
- ค่า factor ที่ MEXC ส่งมาเป็นเลขปัดเศษ และไม่ได้บอกเหตุผลของการหักคะแนน Dashboard จึงชี้ได้แค่ว่าตัวเลขอธิบายการลดไม่ได้ ไม่ได้บอกสาเหตุ

## ความเป็นส่วนตัว

- อ่านด้วย session ของคุณเองในเบราว์เซอร์ของคุณ โดยส่ง GET ไปที่ MEXC เท่านั้น ไม่กดรับรางวัล ไม่เช็กอิน และไม่แก้ไขอะไรในบัญชี
- โค้ดไม่อ่าน cookie และไม่ขอ permission `cookies`
- เก็บเฉพาะคะแนน percentile 5 ด้าน และรหัสบัญชีจาก MEXC ไว้ใน `chrome.storage.local` ไม่ส่งไปที่อื่น และไม่มี analytics
- ไฟล์สำรองมีรหัสบัญชีและประวัติคะแนน ควรเก็บเป็นส่วนตัว

Permission ที่ใช้: `storage` เก็บประวัติ, `alarms` ตั้งรอบอ่าน, `notifications` แจ้งเตือน และ host ของ `mexc.com`, `mexc.co`, `mexc.fm` ใช้อ่านคะแนน

## อัปเดตเวอร์ชัน

ดาวน์โหลดเวอร์ชันใหม่ไปทับโฟลเดอร์เดิม แล้วกด reload ที่ `chrome://extensions` ข้อมูลยังอยู่ อย่ากด **Remove** เพราะข้อมูลจะหายไปกับ extension
